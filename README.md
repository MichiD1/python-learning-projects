# Python Mini Projects

Dieses Repository enthält kleine Python-Projekte, die ich zum Lernen erstellt habe.

## Projekte

### Taschenrechner
Ein einfacher Konsolen-Taschenrechner mit:
- Addition
- Subtraktion
- Multiplikation
- Division
- Prozentrechnung
- Fehlerbehandlung

### Enterprise Infrastructure & VM Manager (Hypervisor Simulation)
Ein praxisnahes Administrations-Werkzeug für Fachinformatiker zur Simulation und Verwaltung virtueller Server-Infrastrukturen (ähnlich VMware vSphere / Proxmox).

- **Technologien**: Python, SQLite3 (SQL)
- **Funktionen**:
  - **Ressourcen-Management (FISI-Fokus)**: Automatische Überwachung von RAM- und CPU-Kapazitäten. Ein Überlasten des Hauptservers (Host) wird durch ein mathematisches Limit (Max. 32 GB RAM) aktiv blockiert.
  - **Server-Lebenszyklus**: Virtuelle Maschinen können im System live provisioniert (erstellt), gestartet (Online), gestoppt (Offline) und deprovisioniert (gelöscht) werden.
  - **Live-Monitoring**: Dynamische Echtzeit-Simulation der CPU-Auslastung bei aktiven Systemen.
- **Lerneffekt**: Verknüpfung von relationaler SQL-Logik mit zentralem Kapazitätsmanagement und Systemzuständen.

### Zahlenratespiel

Maximal 4 Versuche pro Runde.

### Hardware-Lagerverwaltung
Ein interaktives Konsolen-Programm zur Verwaltung von Firmen-Hardware.
- **Technologien**: Python, SQLite3 (SQL)
- **Funktionen**: Geräte im Lager registrieren, gesamte Lagerliste auslesen, Gegenstände gezielt über ihre ID löschen.
- **Lerneffekt**: Praktische Anwendung von relationalen Datenbanken und SQL-Befehlen (`INSERT`, `SELECT`, `DELETE`).
